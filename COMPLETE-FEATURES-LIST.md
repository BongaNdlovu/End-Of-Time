## 🚀 How to Use

### Quick Start:
```bash
# Option 1: Python
python -m http.server 8000

# Option 2: Node.js
npx http-server -p 8000

# Then open: http://localhost:8000
```

### For Presenters:
1. Press **T** - Start timer
2. Press **N** - View notes
3. Press **F** - Fullscreen
4. Press **O** - Overview
5. Press **?** - Help

### For Developers:
- Edit **slides.json** to modify content
- Edit **styles.css** to change appearance
- Edit **app.js** to add features
- All clean and modular!
